# EDA Analysis Project

This project contains an Exploratory Data Analysis (EDA) of a demo customer sales dataset. The analysis includes data cleaning, univariate and bivariate analysis, and visualizations presented as pie charts.

## Files

- `eda .py`: Python script performing the complete EDA analysis.
- `eda_pie_charts.png`: Generated pie chart visualizations
- `README.md`: Project documentation

## Analysis Overview

The EDA covers:
- Dataset overview (1,000 rows, 10 columns)
- Data cleaning (missing values imputation, outlier handling)
- Univariate analysis (distributions, summaries)
- Bivariate/multivariate analysis (correlations, patterns)
- Key business insights and recommendations

## Visualizations

Six pie charts are generated showing:
1. Gender distribution
2. Product distribution
3. Region distribution
4. Customer satisfaction distribution
5. Quantity distribution
6. Age group distribution

## Requirements

- Python 3.x
- pandas
- numpy
- matplotlib
- seaborn
- scikit-learn

## Usage

Run the analysis with:
```bash
python "eda .py"
```

This will generate the report output and save the pie charts as `eda_pie_charts.png`.
